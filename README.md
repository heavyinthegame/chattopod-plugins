# ChatToPod plugins

![ChatToPod](plugins/chattopod/assets/logo.png)

Official plugin packages for ChatToPod by Boson. Ask ChatGPT or Claude to turn your chosen material into a personal Japanese podcast, with the perspective and explanations you need.

The repository contains only public plugin manifests, instructions, README files and icons. The service backend and user data are not included.

## Install

Claude: add this repository as a marketplace from Customize > Plugins > Add > Add marketplace, then install ChatToPod and connect its bundled connector.

ChatGPT: [download the package](https://chattopod.com/downloads/chattopod-chatgpt-plugin.zip) and import it from the plugin page. MCP chat activation currently uses Developer mode until a public listing is approved.

Public store listing is not yet approved. Private installation and marketplace distribution do not imply store approval.
